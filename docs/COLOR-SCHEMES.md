# Цветовые схемы HoReNSo — принципы

## Ограничения платформы
- iPhone 7 / iOS 15, Tailwind v3.
- Только сплошные цвета: без `backdrop-filter`, blend-режимов, `color-mix()` и `oklch`.
- Все цвета — CSS-переменные `--c-*` в виде rgb-триплетов (`247 245 240`), Tailwind читает их как `rgb(var(--c-x) / a)`.

## Единый источник
- Все схемы описаны в `src/lib/themes.ts` в HEX. Больше цвета нигде не задаются.
- `buildThemeCss()` генерирует CSS, `layout.tsx` вставляет его в `<style>`.
- Из тех же данных берутся превью в настройках, `theme-color` и `APPEARANCE_BOOT_SCRIPT`.
- Схема по умолчанию стоит на `:root` первой. Остальные схемы идут как `:root[data-theme=…]`: такой селектор специфичнее, поэтому порядок блоков не важен.

## Что задаётся руками, что выводится
- **Руками:**
  - база: `bg`, `paper`, `ink`, `ink-soft`, `ink-faint`, `line`, `mist`, `shadow`, `selection`;
  - основные цвета: `open`, `acting`, `done`, `ho`, `ren`, `so`.
- **Формулами** (линейная смесь в sRGB при генерации CSS, не CSS-функция):
  - `*-tint`: у светлых `mix(цвет, paper, 20%)`, у тёмных `mix(цвет, bg, 22%)`. Смешивать нужно с `paper`, а не с `bg`, иначе синий на тёплом фоне сереет.
  - `*-ink`: у светлых `mix(цвет, ink, 62%)`, у тёмных `mix(цвет, белый, 70%)`. Если контраст на подложке меньше 4,5:1, текст темнеет шагами по 2 % до 4,5.
  - `*-on` — иконка на сплошной заливке цветом: белая, если её контраст ≥ 3:1, иначе тёмная.
- **`untinted`** — акцент без подложки: `*-tint` = `paper`, цвет виден только в точке, полоске и тексте. Так киноварь в «Туши» не превращается в розовое пятно.
- **Необязательные токены** (`OPTIONAL_TOKENS`). Схема, которая их не задаёт, сбрасывает их в `initial`, а стили читают их как `var(--c-x, запасной)`. Иначе значение из `:root` «протекает» в чужую схему.

## Правила использования в интерфейсе
- Текст и иконки на подложке `*-tint` рисуются только цветом `*-ink`, основной цвет для текста не используется.
- Основной цвет идёт на точки, полоски и тонкие рамки.
- Активный статус выделен тонкой рамкой своего цвета (`ring-current`), поэтому он заметен и без подложки.

## Характер палитр
- Акценты минеральные и земляные, пудровые и «кондитерские» (розовый, персиковый, сиреневый) не используются.
- У каждой цветной схемы свой набор в её характере, а не сдвиг общей палитры:
  - **Слоновая кость:** охра, сталь, шалфей, умбра.
  - **Туман:** сталь, эвкалипт, сланец.
  - **Аи** (藍, «индиго»): индиго, хвоя, умбра, охра. Заменила «Сакуру».
  - **Маття:** хвоя, ходзича, селадон.

## Группа «Тушь»
- **Тушь:** бумага `#F4F3EF`, тушь `#1A1A19`, статусы и Хо/Рен/Со — оттенки туши.
- **Тушь с пометками:** та же база, пометки — умбра `#8A6428`, хвоя `#3B6B5F`, индиго `#34507C`, олива `#66703A`, кирпич `#9A4536`.
- **Суми:** тёмная, уголь `#161615`, светлые линии. На светлых заливках иконки тёмные.
- Единственный яркий цвет всей группы — киноварь: `#C8432B`, в тёмной `#E0583D`. Она только у `open` («Требует мер»), на светлых схемах без подложки.
- **Как в системе** (`auto`): днём «Тушь с пометками», ночью «Суми». Переключается через `@media (prefers-color-scheme: dark)`, без JS. Цвет панели Safari задают два `<meta name="theme-color">` с `media`.

## Проверка — `npm run check:colors`
Запускать перед коммитом. Скрипт печатает таблицу по схемам и завершается с кодом 1 при нарушении. Пороги:

| Что | Порог |
|---|---|
| RGB-расстояние внутри `open/acting/done` и внутри `ho/ren/so` | ≥ 30 |
| `*-ink` на `*-tint` | ≥ 3,5:1 (статусы ≥ 4,5:1) |
| `ink-faint` на `bg` | ≥ 3:1 |
| Тёмные схемы: `*-on` на заливке `*` | ≥ 3:1 |
| CSS | `:root` первым, каждая схема — `:root[data-theme=…]` |

## Совместимость настроек
- `THEME_ALIASES` переводит удалённые схемы на замену: `sakura` → `ai`.
- «Сумиэ» стала «Суми» с тем же id `sumi`.
- Хранилище настроек (версия 2) мигрирует сохранённый выбор, загрузочный скрипт учитывает псевдонимы ещё до гидрации.
