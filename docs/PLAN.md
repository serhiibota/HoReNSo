# Хо-Рен-Со — план реализации

## Шаг 1. Фундамент (сделано)
- Next.js **15** (App Router) + TypeScript + Tailwind CSS **3.4** + Zustand 5.
- Почему не новее: Next.js 16 и Tailwind 4 официально требуют Safari 16.4+
  (Tailwind 4 генерирует `oklch`, `@property`, `color-mix`). На iOS 15 это
  сломает стили и сборку, поэтому версии зафиксированы.
- `output: 'export'` — полностью статическое приложение, сервер не нужен.
- `browserslist` в `package.json` включает `ios_saf >= 15` — Autoprefixer
  добавит `-webkit-` префиксы, SWC транспилирует JS под Safari 15.

## Шаг 2. Дизайн-система (сделано)
- Палитра в `tailwind.config.ts`: слоновая кость `#F7F5F0`, белые карточки,
  тёплый графит для текста; пастельные акценты статусов и Хо/Рен/Со.
- Типографика: Cormorant Garamond (заголовки) + Manrope (текст), обе с
  кириллицей, самохостятся через `next/font` — без запросов к Google в рантайме.
- `backdropBlur` и `backdropFilter` отключены в `corePlugins`: утилиты
  с размытием невозможно случайно использовать.

## Шаг 3. Данные (сделано)
- `src/lib/types.ts` — модель `Entry` (факты, мысли, статус, история коммуникаций).
- `src/store/entries.ts` — Zustand + `persist` → `localStorage` (ключ `horenso:v1`).
  Черновик тоже сохраняется: iOS Safari выгружает фоновые вкладки.
- `skipHydration` + `useHydrated()` — нет расхождения SSR/клиент,
  пока данные не прочитаны, показывается скелетон.

## Шаг 4. Форма записи (сделано)
- Вкладки «Что я вижу / Что я думаю» (`SegmentedControl`) + свайп влево/вправо.
- Панели едут через `translate3d`; после перехода неактивная панель
  сворачивается, чтобы высота страницы соответствовала текущей.
- На десктопе (`lg:`) обе панели стоят рядом, вкладки скрыты.
- `AutoTextarea` растёт по `scrollHeight` (`field-sizing` в Safari 15 нет).
- Шрифт полей 16px — iOS не зумит страницу при фокусе.
- Нижняя кнопка уезжает вниз, пока открыта клавиатура.

## Шаг 5. Лента и карточка (сделано)
- Лента с фильтрами по статусу, цветная полоса статуса слева, баннер черновика.
- Экран записи: переключатель статуса (Требует мер → Меры приняты → Есть результат),
  история коммуникаций.
- Нижняя панель Хо / Рен / Со → шторка с резюме → «Копировать» / «Поделиться».
  Резюме меняет порядок блоков под тип коммуникации (для «Со» вопрос идёт первым).

## Шаг 6. Мобильные детали (сделано)
- `viewport-fit=cover` + `env(safe-area-inset-*)` для всех fixed-элементов.
- `-webkit-fill-available` вместо `100vh` на iOS (`dvh` появился лишь в 15.4).
- Блокировка прокрутки фона под шторкой через `position: fixed` на `body`
  (`overflow: hidden` в iOS Safari не работает).
- Копирование: `navigator.clipboard`, при отказе — `execCommand('copy')`.
- Без `crypto.randomUUID`, `Array.at`, `structuredClone`, `<dialog>` — их нет в iOS 15.0–15.3.

## Шаг 7. Оформление (сделано)
- Шторка «Оформление»: группы «Тушь» (Тушь, Тушь с пометками, Суми, Как в системе)
  и «Цветные» (Слоновая кость, Туман, Аи, Маття) + 4 пары шрифтов.
- Цвета — единый источник `src/lib/themes.ts`, CSS генерируется `buildThemeCss()`.
  Принципы и проверка — [COLOR-SCHEMES.md](COLOR-SCHEMES.md), `npm run check:colors`.
- Выбор хранится в `localStorage` (`horenso:prefs`) и применяется скриптом
  в `<head>` до первой отрисовки, там же обновляется `theme-color`.

## Шаг 8. Режим самопроверки (сделано)
- Хо-Рен-Со — правило рабочей коммуникации; перед ним полезно проверить себя.
  При создании записи — «Для себя» (самопроверка) или «Для команды» (Хо-Рен-Со);
  новая запись начинается в режиме последней сохранённой.
- В фактах самопроверки подсвечиваются слова-выводы (`src/lib/markers.ts`):
  обобщения, оценки, домыслы — строкой под полем, без оверлея в textarea.
- «Что я думаю»: моя версия, другие объяснения, чувства, уверенность 0–100 %,
  как проверить. На экране записи — итог (пока неясно / подтвердилось /
  не подтвердилось) и «Вывод для себя».
- «Сказать команде» переводит запись в Хо-Рен-Со; вопросы самопроверки,
  итог и вывод остаются в блоке «Самопроверка».
- Хранилище записей v2: старые записи мигрируют как «для команды».

## Шаг 9. Журнал решений и инструменты (сделано)
- Запись — это решение: вопрос, варианты, выбор, уверенность, дата пересмотра.
  Создание — `/decide`, карточка — `/entry`, инструмент — `/tool?id=…&t=…`.
- Инструменты (`src/lib/tools.ts`), любые и в любом порядке:
  «Факт или вывод» (прежняя форма Вижу/Думаю), «За и против» с весами
  и видом «квадрат Декарта», «10/10/10», «Премортем», «Обратимость».
- Пересмотр: при наступлении даты — метка в ленте и на карточке (push на
  iOS 15 в вебе недоступен). Решение и результат оцениваются отдельно;
  сочетание даёт вывод: заслуженный успех / невезение / повезло / урок.
- Хо/Рен/Со — финальный шаг «Сообщить решение»: в текст попадают вопрос,
  выбор, уверенность и содержание инструментов.
- Хранилище записей v3: старые записи получают пустые поля решения.

## Шаг 10. Дальше (идеи)
- Инструменты «Совет другу» и «Сценарии: лучший / худший / вероятный».
- Статистика пересмотров: насколько точна уверенность («калибровка»).
- Поиск по записям, экспорт/импорт JSON (резервная копия localStorage).
- Service Worker для офлайн-режима (PWA уже можно добавить на экран «Домой»).
- Напоминание «закрыть цикл» для записей, которые долго висят в «Требует мер».
- Тесты: Vitest для `buildSummary` и стора, Playwright WebKit для сценариев.

## Структура

```
src/
├── app/
│   ├── layout.tsx          # шрифты, viewport-fit=cover, метаданные PWA и иконки
│   ├── globals.css         # safe area, -webkit-fill-available, анимации
│   ├── page.tsx            # лента
│   ├── new/page.tsx        # создание / редактирование (?id=)
│   ├── entry/page.tsx      # просмотр записи + Хо/Рен/Со (?id=)
├── components/
│   ├── EntryForm.tsx       # форма: вкладки Вижу/Думаю, свайп, нижняя кнопка
│   ├── FieldList.tsx       # карточка-«страница блокнота» с полями
│   ├── AutoTextarea.tsx    # авто-рост высоты
│   ├── SegmentedControl.tsx
│   ├── Feed.tsx            # лента, фильтры, черновик, пустое состояние
│   ├── EntryCard.tsx       # карточка ленты с цветом статуса
│   ├── EntryView.tsx       # экран записи, выбор статуса
│   ├── CommBar.tsx         # нижняя панель Хо / Рен / Со
│   ├── SummarySheet.tsx    # резюме + копировать / поделиться
│   ├── BottomSheet.tsx     # шторка: translate3d, свайп вниз, scroll lock
│   ├── HelpSheet.tsx       # методология («?»)
│   ├── SettingsSheet.tsx   # цветовые схемы и шрифты
│   ├── AppearanceSync.tsx  # применяет выбор к <html>
│   ├── Fab.tsx, TopBar.tsx, StatusBadge.tsx, icons.tsx
├── lib/
│   ├── types.ts, fields.ts # модель и тексты полей/статусов
│   ├── themes.ts           # схемы (HEX), формулы подложек, buildThemeCss
│   ├── appearance.ts       # шрифты, theme-color, скрипт до гидрации
│   ├── summary.ts          # генерация текстового резюме
│   ├── share.ts            # clipboard + Web Share API с фолбэками
│   ├── format.ts, id.ts, nav.ts
└── store/
    ├── entries.ts          # Zustand + localStorage
    └── useHydrated.ts
```
