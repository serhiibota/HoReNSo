# Хо-Рен-Со

Минималистичный блокнот для осознанной коммуникации по японскому принципу
**報連相** — Хококу (сообщить), Ренраку (информировать), Содан (посоветоваться).

Вижу → думаю → решаю, как сказать. Сначала фиксируете факты, затем анализ,
затем выбираете тип коммуникации и получаете готовое текстовое резюме.

Оптимизировано под **iPhone 7 / 7+ на iOS 15**: без `backdrop-filter`,
анимации только через `transform`, учёт safe area и нижней панели Safari.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # статическая сборка в out/
npm start          # раздать out/ локально
```

Проверить на iPhone в одной сети: `npm run dev -- -H 0.0.0.0`, открыть
`http://<ip-компьютера>:3000`. «Поделиться» и `navigator.clipboard` требуют
HTTPS — по обычному HTTP копирование идёт через запасной путь.

Данные хранятся только в `localStorage` браузера.

План и структура — в [docs/PLAN.md](docs/PLAN.md).
